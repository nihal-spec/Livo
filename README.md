# Livo

This repository is for a planning tool for temporary living, relocation and trips. It helps people work out where to stay near their office, hospital, college or other destination, and what it will really cost, including rent, deposit, food, commute and a buffer.

**Status:** planning only. No application code has been written yet.

The planning documents are in [`docs/planning/`](./docs/planning/). Start with [`MASTER_PLAN.md`](./docs/planning/MASTER_PLAN.md).
